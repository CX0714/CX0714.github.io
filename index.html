外观

气泡
1 = 最紧凑（贴合文字），3 = 最宽松
直接粘贴 CSS 属性，会覆盖默认样式（如背景色、圆角等）
时间
你发消息后，他会在 0 秒 ~ 这个时长之间随机延迟，然后回复。0 = 秒回；3600 秒 = 最长等 1 小时。
他主动找我说话
开启后，他会不定时主动给你发一条字卡（需要页面开着）。
他会在「最短 ~ 最长」之间随机挑一个时间点主动发消息。你不在页面时不会发，回到页面后会自动补发（最多 3 条）。
静音保活
像后台放音乐一样循环播放一段无声音频，尽量让手机别冻结页面，让「主动发消息」更持久。会更耗电，锁屏界面可能显示「正在播放」。
字卡库
文字是他回复的主体。你发消息后，他会随机挑 1~2 条作为回复。
emoji 会随机附加在文字前后一起发送（也可能不加）。
表情包作为独立一条消息发送（约 30% 概率）。从照片导入，会自动压缩保存。
数据管理
恢复出厂设置会清除所有数据（包括字卡、设置、聊天记录），请谨慎操作。
关于

这是一个专属于你和他的私人对话空间。
所有他说的话，都来自你亲手写下的字卡。
愿每一句回复，都能温暖你。💛
